# Contributing

This repository hosts Luna Park product information, bug reports, and feature requests. The proprietary editor source is maintained separately.

## Bug reports

Search [existing issues](https://github.com/lunapark/lunapark/issues) before opening a [bug report](https://github.com/lunapark/lunapark/issues/new?template=bug_report.yml). If the problem is already reported, add useful reproduction details to that issue.

Include the Luna Park version, whether you use the browser or desktop editor, your operating system and browser versions, clear reproduction steps, and the expected and actual results. Reduce the problem to the smallest project or example that demonstrates it.

Screenshots and diagnostic text can help. Review them before posting: remove API keys, activation keys, personal data, and private project content or paths.

## Feature requests

Use the [feature request form](https://github.com/lunapark/lunapark/issues/new?template=feature_request.yml). Explain the problem you want to solve, your proposed behavior, and any current workaround. Concrete examples help us understand the request.

## Creating plugins

You can create plugins to extend Luna Park with new components, visual nodes, and integrations. Start with the [plugin boilerplate](https://github.com/lunapark/plugin-boilerplate) and consult the [plugin documentation](https://luna-park.app/docs/plugins).

Plugins must not replicate or compete with the functionality of paid Luna Park plugins provided by the Luna Park team.

## Questions and support

Ask usage questions on the [community forum](https://forum.luna-park.app/) or [Discord](https://discord.gg/2eAk2AHvdw).

## Documentation changes

Pull requests improving this repository's product information, links, and feedback instructions are welcome. Keep changes focused, write in English, and explain what was inaccurate or unclear.

Check Markdown rendering and links. For changes to issue forms, check YAML syntax and the GitHub issue-form structure. Application builds and tests are not needed for this documentation repository.
